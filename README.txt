MIDIMAN WEBSITE — QUICK START

1. Extract this ZIP.
2. Open index.html locally to preview the site.
3. In your GitHub repository, upload ALL files from this folder:
   - index.html
   - style.css
   - script.js
   - favicon.svg
4. Commit the changes to your main branch.
5. GitHub Pages will publish the updated site automatically.

CUSTOMIZE:
- Edit the text in index.html.
- Change colors near the top of style.css under :root.
- Add your real projects by editing the project cards.
- Replace hello@midiman.shop in index.html with your preferred contact email.

The site uses Google Fonts when online; it has system font fallbacks.
The email link is a placeholder until you replace the address.
